# Lassa-Fever-Predictor-Mobile-Application
The lassa fever locations predictor is an invention that relates to mobile health and geospatial surveillance systems and more importantly a cross platform mobile application that converts 
machine learning based SDM predictions into an interactive offline capable tool for predicting lassa fever reservoir host habitat suitability in Nigeria
The application provides a GPS integrated field data collection interface that allows worker to record new presence or absence observations directly on a smartphone,
the application is offline based when no network is available observation can be recorded locally and automatically synchronised into the server once connectivity is restored,
so surveillance data can be collected continuously in remote areas.Newly collected field observation feedback into the system to support future retaining of the predictive model,
thus creating a form of validation between model predicted locations and the ground truth data.
